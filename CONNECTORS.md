# Conectores

kumiko no necesita ningún conector externo. Todo lo que usa vive en el repositorio del
cerebro: markdown, un `kumiko.json` y tres scripts de Python sin dependencias.

La única pieza opcional es el servidor MCP, que corre en local y necesita el paquete `mcp` en un Python >= 3.10 (`sh motor/instalar.sh` lo deja en `~/.kumiko/venv`).
